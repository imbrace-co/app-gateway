# App Gateway

## Overview

This project is an API Gateway built with Express.js. It includes features such as rate limiting, proxy middleware, and more.

## Getting Started

### Prerequisites

Ensure you have the following installed:

- Node.js
- Yarn (or npm)
- Git

### Installation

1. Clone the repository:
   ```sh
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```sh
   cd app-gateway
   ```
3. Install dependencies:
   ```sh
   yarn install
   ```

### Running the Application

#### Build

To build the project, run:

```sh
yarn build
```

#### Start

To start the application, run:

```sh
yarn start
```

#### Development

For development purposes, use:

```sh
yarn dev
```

### Linting

To lint the code, run:

```sh
yarn lint
```

To automatically fix linting issues, run:

```sh
yarn lint:fix
```
